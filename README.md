## Repository for ML-based corrections to central Great Plains diurnal cycle of precipitation

* model architecture used for manuscript outlined in simple.py, with model components from Components.py
* data pre-processing done using file_utils.py
* plots are derived within precip_analysis.ipynb and relevant imported files
* custom PyTorch data loader in OTPrecipDataset.py
* MCS-based filtering done in mcs_data.py
* models trained using train_model.py
